# Portfólio — Lucas Andrade

Landing page de portfólio pessoal, feita em HTML, CSS e JavaScript puros (sem build, sem dependências).

## Conteúdo

- Hero com apresentação e estatísticas
- Seção "Sobre mim"
- Stack / habilidades
- Projetos em destaque
- Contato e redes sociais

## Como editar

1. Abra `index.html`.
2. Troque o nome, textos e links pelos seus dados reais.
3. Os projetos estão na seção `#projetos`; cada card tem título, descrição e link.

## Rodar localmente

Basta abrir o `index.html` no navegador, ou:

```bash
npx serve .
```

## Deploy

Publicado via GitHub Pages a partir da branch `main`.
